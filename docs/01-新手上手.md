# 新手上手

当前方案：**Core 直连外部 STT/LLM/TTS，云端保存和检索完整记忆，手机或电脑通过 PWA 网页按需管理。** 不开发必需的原生 iPhone App，Core 不运行 Whisper、高质量 TTS 或完整 LLM。

## 你需要准备什么

- 三件实物：StackChan Core、Faces Bottom3、Faces Gamepad3；可传数据的 USB 线、稳定供电、2.4GHz Wi-Fi；microSD 建议用于动画和有限缓存。
- Windows 电脑，项目目录 D:\m5Lunar。安装 Arduino IDE、Git；网页与记忆服务阶段安装兼容的 Node.js。
- 后续选定 AI 服务账号、云端记忆服务、预算与角色素材。现在不需要购买服务器，也不需要 Mac/Xcode。
- iPhone Safari 用于验证添加主屏幕与管理操作；普通电脑浏览器也可以使用。

## 工具与第一次运行

1. 按 [M5Stack 板管理教程](https://docs.m5stack.com/en/arduino/arduino_board) 安装板包。
2. 按 [StackChan 显示示例](https://docs.m5stack.com/en/arduino/stackchan/display) 配置板选项和库；实际测试版本记入记录。
3. 在 Windows 设备管理器确认 COM 端口，Arduino 点“验证”再“上传”。屏幕显示正常后才继续八键、触摸和音频例程。
4. 用 Gamepad3 对应版本例程检查每个按键按下/松开；用短录音回放验证音频。
5. 后续按 [Vite 官方指南](https://vite.dev/guide/) 安装兼容 Node；建议 Node 22.12 或更高兼容版本，最终由锁文件固定。

看不到 COM 先换数据线与接口；编译报错保存第一条错误和版本；按键异常核验总线，不随机试 GPIO。当前没有业务源码，文档不会把尚不存在的工程启动命令写成已可运行。

## 常用词

| 名词 | 白话解释 |
|---|---|
| 固件 / 编译 / 烧录 | 设备程序 / 转成可执行文件 / 写进设备 |
| HAL | 屏幕、按键、音频等硬件的统一接口 |
| STT / LLM / TTS | 语音转文字 / 对话文字模型 / 文字转声音；本项目都远程运行 |
| Provider | 适配某家服务接口的代码 |
| PWA | 可添加到主屏幕的网页应用 |
| 主库 / 缓存 | 完整权威数据 / 有大小上限的本地副本 |
| Outbox | 尚未被云端确认保存的新事件队列 |
| revision / epoch | 数据版本 / 主库恢复迁移后的世代 |
| Mock | 用固定假响应测试，不调用付费模型 |
| 幂等 | 同一操作重试多次只生效一次 |

## 按什么顺序做

读 [总体架构](02-总体架构.md)，按 [开发路线](03-开发路线与任务清单.md) 从 M0 开始。先做硬件和离线 Home，再做一次真实 STT 和一次真实 TTS；随后云端记忆和 PWA，最后完善旅行、备份和升级。

一项任务交付后必须给实际编译/运行步骤、依赖版本、通过和未通过的测试。没有硬件时可写 Mock 和测试规则，但不能将模拟当作实机通过。素材不齐先用标注的占位角色。

你可以逐项提出：“实现 T00，提交测试固件和步骤，并说明哪些需要我连接设备验证。”不用一次学会全部工具。
