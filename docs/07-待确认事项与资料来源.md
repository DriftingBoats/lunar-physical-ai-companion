# 决策与官方资料

核验日期2026-09-09；现阶段为设计，不是实测证明。

## 已确认与工程建议

| 编号 | 状态 | 结论 |
|---|---|---|
| D01 | 用户确认 | 通用角色/形象/人格/声音可换，Lunar默认 |
| D02 | 用户确认 | 虚构故事、真实交互、用户自述分别存储检索 |
| D03 | 当前方案 | Core直连外部AI，不本地跑Whisper/TTS/LLM |
| D04 | 用户最终选择 | 云端主记忆＋Core有限缓存 |
| D05 | 用户确认 | 网页PWA管理，可添加iPhone主屏幕；原生App非必需 |

| D07 | 建议默认 | 一次性提醒、稍后10分钟；记忆查询2秒截止；缓存等预算见05 |
| D08 | 后续可选 | iPhone主库、全功能音频后端、4G、embedding检索 |

## 待确认事项

| 事项 | 何时需要 | 验证方法 |
|---|---|---|
| 三件硬件型号/引脚/供电 | M0 | 标签、原理图、联合例程、充放电 |
| 底座电量读数是否可用 | M0 | 比较真实供电状态，不可信则未知 |
| 本地动态泰文排版 | M0–M1 | 字体/组合符号/分页专项探针 |
| AI供应商、模型和音色 | M2 | 真实网络、格式、中泰质量、延迟与费用 |
| 云记忆地区/服务/预算 | M3 | 冷热查询、TLS、1万条测试、权限 |
| 正式Lunar图像和样音 | 正式角色验收 | 用户认可原稿和干净样音；概念图非资源包 |
| 蜂窝模块与电池续航 | 后续 | 峰值电流、频段、引脚、温升、实测时长 |

没有这些输入也能先做Mock与硬件例程，不应编造最终值。PWA路线无需Mac/Xcode；只有重启可选原生iPhone路线时才需要。

## 官方来源

1. [StackChan Core](https://docs.m5stack.com/en/core/StackChan_Core)：C156、ESP32-S3、16MB Flash/8MB PSRAM、320×240及音频；Wi-Fi/BLE。
2. [Faces Bottom3](https://docs.m5stack.com/en/faces/Faces_Bottom3)：A168、600mAh、充电与总线；完整组合仍需验证。
3. [Gamepad3](https://docs.m5stack.com/en/faces/Faces_Gamepad3)：A004-V3、八键、I²C 0x08。
4. [Gamepad3示例](https://docs.m5stack.com/en/arduino/projects/faces/faces_gamepad3)：M5Faces与内部I²C，不照搬旧代库。
5. [StackChan显示](https://docs.m5stack.com/en/arduino/stackchan/display)：页面列M5CoreS3板选项、板包≥3.2.2、M5Unified≥0.2.11、M5GFX≥0.2.18；最终版本实测固定。
6. [麦克风示例](https://docs.m5stack.com/en/arduino/stackchan/mic)：只验证录音，不代表云识别已接入。
7. [Espressif OTA](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-reference/system/ota.html)：分区与回滚；Arduino构建需专项验证。
8. [HarfBuzz](https://harfbuzz.github.io/what-is-harfbuzz.html)：字体之外还需字形定位/排版。
9. [Vite](https://vite.dev/guide/)：网页环境与Node要求。
10. [PWA安装](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)：manifest/HTTPS、主屏幕与平台差异。
11. [Web Bluetooth](https://developer.mozilla.org/en-US/docs/Web/API/Web_Bluetooth_API)：不是可假定所有浏览器支持的通用接口；当前配网不依赖它。
12. [Supabase权限](https://supabase.com/docs/guides/database/postgres/row-level-security)、[函数](https://supabase.com/docs/guides/functions)：托管候选，尚未选定或开通。
13. [Apple蓝牙恢复](https://developer.apple.com/documentation/technotes/tn3115-bluetooth-state-restoration-app-relaunch-rules)：可选iPhone主库后台限制。
14. [Xcode](https://developer.apple.com/xcode/)：仅可选原生路线需要。
