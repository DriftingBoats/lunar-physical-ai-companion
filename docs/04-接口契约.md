# 当前接口契约 v0.3

主链路：Core→服务商 AI；Core/PWA→轻量记忆与配置 API。这里定义项目 API，不是让 AI 服务商实现 /audio-jobs；完整音频后端协议仅保留在 optional/backend。

## 1. 公共规则

项目路径前缀 /api/v1，UTF-8 JSON、UTC ISO 8601 时间、随机ID。revision 为服务端递增版本；authority_epoch 标记恢复/迁移世代。响应为 data+request_id，列表 items+next_cursor；错误 error={code,message,retryable}。

设备 Bearer token；PWA建议同源会话Cookie（HttpOnly/Secure/SameSite）及写操作CSRF校验，由托管身份服务登录后换取应用会话。实际实施锁定一种会话模式，不混用两套登录。所有资源从身份限定owner和companion，不信任客户端owner_id。GET不返回服务密钥。

写操作带 Idempotency-Key；同身份/路径/键/请求只生效一次，同键异内容409。保留至少7天，事件另用永久唯一event_id。修改带base_revision，冲突409不覆盖。

错误：400/422 INVALID_INPUT；401 TOKEN_EXPIRED；403 FORBIDDEN；409 REVISION_CONFLICT；413 PAYLOAD_TOO_LARGE；429 RATE_LIMITED；503 UNAVAILABLE；504 TIMEOUT。游标过期返回409 SYNC_RESET_REQUIRED，客户端保留outbox重取快照。

## 2. 配对与认证

| 方法 / 路径 | 调用与结果 |
|---|---|
| POST /pairing/start | 设备bootstrap认证→pair_id、8位code、5分钟有效期 |
| POST /pairing/claim | PWA已登录提交code→认领；设备显示脱敏账号 |
| GET /pairing/{id} | 发起设备查询认领状态 |
| POST /pairing/{id}/confirm | 设备实体A确认→绑定companion及作用域设备token |
| POST /devices/{id}/token/rotate | 当前有效设备认证→新token；短期交接后撤销旧token |
| DELETE /devices/{id}/binding | 所有者撤销绑定与令牌，记忆默认保留 |

bootstrap凭据在开发阶段经USB注入，生产发行流程另行固化，不能是所有设备共用公开密码。code一次有效、5次失败冻结本次尝试，实体确认60秒超时。过期且无法续期的token重新配对；设备ID不作为认证。

## 3. 记忆检索

POST /memories/query，设备token或管理用户会话：

```json
{"query":"上次翻译","scope":"real","limit":5,"max_bytes":8192,"authority_epoch":1}
```

query≤1024 UTF-8字节；scope=real/story/mixed；limit≤5；正文结果≤8KiB。服务端先权限、删除、来源过滤，再检索；real排除fictional_trip，mixed也区分来源。

```json
{"data":{"retrieval_status":"complete","index_revision":12,"authority_epoch":1,"records":[{"id":"mem_demo","revision":1,"source_type":"shared_experience","content":"完成一次中泰翻译。","evidence_event_ids":["evt_demo"],"character_preset_id":"lunar","character_version":1}]},"request_id":"req_demo"}
```

设备2秒总截止（含建连）后回退缓存，晚到结果不重做LLM请求。complete仅指查询完成；空结果与超时不同，不凭空补造记忆。

## 4. 事件与同步

POST /devices/{id}/sync 输入 cursor、authority_epoch、applied_config_revision、events。每批≤10条且≤32KiB。事件含 event_id、type、source_type、occurred_at、character版本、payload。类型允许translation.completed、reminder.completed、trip.returned、memory.save_requested。

返回 accepted_event_ids、rejected_events（原因与可重试标志）、changes、next_cursor、has_more、server_time、authority_epoch。change={entity,id,revision,operation:upsert/delete,data}；delete无正文。只有事务持久化后才accepted；重复事件返回原确认。

先下发删除，再普通变更；设备原子保存后提交游标。未确认outbox不能丢。新epoch需恢复/迁移确认后重取快照，不盲目接受不认识的主库。

## 5. 管理端 CRUD

| 方法 / 路径 | 说明 |
|---|---|
| GET /companions/{id}/memories | query/source_type/cursor，默认20最大100 |
| POST /companions/{id}/memories | 手动输入只能user_reported |
| PATCH /memories/{id} | base_revision、title/content；来源不可改 |
| DELETE /memories/{id} | 墓碑、索引过滤、缓存删除变更 |
| GET/POST /companions/{id}/profile | 用户事实与证据；不能有故事证据 |
| PATCH/DELETE /profile/{id} | 修改/删除及依赖清理 |
| GET/DELETE /companions/{id}/recent-context | 查看/清空摘要，删除数据不重生 |
| GET/PUT /companions/{id}/config | 完整desired配置；PUT带base_revision |
| GET /devices/{id}/config | 应应用快照与资源manifest |
| POST /devices/{id}/config-ack | revision、applied/rejected；成功落盘才applied |
| GET /character-presets | 可用预设与版本 |
| POST /character-presets | 草稿校验后发布不可变版本 |
| GET /plugins | 内置manifest、状态、能力 |
| POST /devices/{id}/heartbeat | 每60秒建议上报，3分钟未收到显示离线 |

配置包括角色、生活、brain profile、插件、音量亮度。provider secret仅写、服务端加密保存，授权设备取自身密钥配置时走独立受限端点 POST /devices/{id}/credential-delivery；设备确认后配置页只显示是否已配置。云管理密钥永不下发。自定义AI key是用户本人密钥，不是共享平台key；USB本地配置也可用。

## 6. 提醒

GET/POST /companions/{id}/reminders；PATCH /reminders/{id} 支持edit/complete/snooze/cancel，带base_revision和event_id。存title、due_at、timezone、status、applied_device_revision。

Core本地创建先落盘即本机生效，再同步；网页创建云端保存后显示pending_device，设备拉取落盘并ack才显示applied。completed/cancelled优先于旧snooze；冲突返回最新终态，不复活提醒。

## 7. 资源、备份与发布

POST /assets/uploads申请本人作用域受限上传；GET /assets/{id}/manifest返回type/bytes/hash/expiry与短期下载授权；媒体私有，按归属鉴权。角色包上传/解压限量与路径校验。

POST /companions/{id}/exports 创建异步备份；GET /tasks/{id} 查看queued/running/succeeded/failed；备份下载过期需重新授权。POST /companions/{id}/imports/preview校验包和冲突，POST /imports/{id}/apply执行恢复，删除账本优先。

GET /devices/{id}/release返回签名固件manifest；固件音频不经过记忆API。AI端点和编码由09文档的provider适配单独定义。

## 8. 契约验收

跨用户查改删、未绑定设备、token撤销、重复event、旧revision、超大body、游标过期、删除后旧缓存、配置未ack、提醒未到设备、备份任务中断、2秒超时回退。实施时生成OpenAPI/JSON Schema和可运行契约测试，当前仅设计。

## 9. 分层记忆扩展（schema v2）

与 [分层记忆规格](12-人格关系与分层记忆系统.md) 配套。旧客户端不支持时仅提供兼容查询，不下发主动回忆任务。新增事件 conversation.memory_candidate 和 memory.proactive_preference；前者只提交必要文本片段及说话时间，模型提取的内容标候选，程序验证来源，不能把模型生成内容当用户原话。

POST /memories/query 可附 context={now,timezone,clock_valid,character_preset_id,character_version}、retention_tiers、subject_refs、as_of。服务端校验时间合理性，响应records保留tier/kind/realm/时间/认识状态/score摘要；relationship_context只返回少量已确认信息。整个data继续≤8KiB，不能给关系摘要另开无限预算。

| 方法 / 路径 | 语义 |
|---|---|
| GET /memories/{id}/score | 分项、理由、模型/规则版本与人工覆盖历史 |
| PATCH /memories/{id}/policy | 用户会话；base_revision、tier、user_pinned、score_override、proactive_policy；不允许改来源 |
| GET/PATCH /companions/{id}/relationship | 已确认称呼/关系/边界，PATCH带base_revision；推断状态不可默默变确认 |
| GET /companions/{id}/character-learning | 待接受、拒绝与历史候选 |
| POST /character-learning/{id}/decision | accept/reject+base_revision；接受发布新preset，不由AI直接调用 |
| GET/PUT /companions/{id}/recall-settings | 开关、勿扰时段、日额度、间隔、不再提及；PUT带base_revision |
| GET /devices/{id}/recall-candidates | 最多3个、总≤8KiB、带有效窗、证据版本和角色版本；无候选返回空 |
| POST /recall-plans/{id}/validate | 设备认证、当前角色/时间/焦点；在线校验后原子预留额度并发一次性授权 |
| POST /recall-plans/{id}/receipt | displayed/accepted/skipped/expired，唯一delivery_id，幂等写入 |

重要性评分请求由内部异步任务发起，不提供设备可任意付费重评分的公开入口。任务有预算、deadline、版本和至多一次自动重试；失败为pending/failed，查询不等待它。

validate的授权最长30秒，Core还要在展示当刻本地检查焦点和勿扰。授权被消费或过期不能再次展示；一次预留计入当日额度，即使回执丢失也不自动返还额度，优先避免重复打扰。删除/禁提使未授权候选立即失效；已发30秒授权存在网络竞态，PWA显示可能待设备撤销，不能承诺离线瞬时擦除。Core收到撤销即停止，不能把旧授权长期缓存。

新增验收：高分不相关、过期与superseded过滤、未知时间、短期到期不删提醒、重复评分、删除证据级联、原子日额度、同计划重试、切角色后旧授权、关闭主动但Reminder仍工作。

## 10. Ombre 参考后的 v2 补充

详见 [实现方案](13-Ombre-Brain参考与记忆实现方案.md)。v2 当前尚未实现：补充 memory_kind=reflection、source_type=companion_reflection；只有云整理路径可生成自省，设备事件不能任意声明此来源。旧客户端遇到未知类型应忽略该记录，不映射为事实。

query 可选 retrieval_mode=explicit/context，默认 explicit；内部 proactive 模式不向设备开放。普通事实记录排除 reflection；对话上下文由独立通道最多附1条相关反思，仍与全部结果共享5条/8KiB。响应可带 source_refs、surface_state；完整 affect 与解释信息按需在PWA详情读取，Core不下载全部审计元数据。

GET /memories/{id}/evidence：仅用户管理会话；按记忆归属及证据有效引用授权，默认最多返回4KiB必要片段，以签名游标分页。不能仅凭 source_id、标题或内容哈希读任意原文；先查删除/版本/引用范围。响应标记 untrusted_history=true；原话与模型摘要清楚区分。读取不刷新活跃度。

独立重提由真实 conversation 事件经云校验产生，记忆ID、源版本与event_id幂等；不提供模型可任意调用的“增加活跃度”接口。原文删除、纠正沿用已有记忆操作与revision规则，触发共享证据处理和派生项失效。
