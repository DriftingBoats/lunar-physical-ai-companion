# M09 独立后端与 AI 适配｜需求（可选扩展）

当前推荐路线为设备直连，详见 [直连方案](../../09-设备直连开发基线.md)。本模块只在将来需要集中管理、多设备同步或复杂检索时实施，不是首版前置条件。

| 编号 | 需求 |
|---|---|
| BE-01 | 将供应商差异封装在统一的 STT、Conversation、Translation、TTS、Weather 接口 |
| BE-02 | Mock 模式不调用外部付费服务，仍可测试完整业务 |
| BE-03 | 每个请求鉴权并限定数据所有权，设备 ID 不能充当密码 |
| BE-04 | 音频任务异步、可取消、有截止时间，重试不重复写动作 |
| BE-05 | 记忆来源校验、世界规则和提醒保存由程序执行 |
| BE-06 | 模型配置区分简单档位与高级配置，支持能力测试 |
| BE-07 | 保存请求耗时、错误码和用量，不默认保存完整私密对话 |
| BE-08 | 进程重启后任务有终态，不永远 processing |

未选择具体供应商或购买服务器；自定义 provider 不代表任意接口都兼容。新增服务必须实现并测试适配器。方案见 [development](development.md)。

验收：Mock 完整流程、真实服务最小流程、配额不足、非法响应、超时、跨用户访问、任务重启和重复提交。
