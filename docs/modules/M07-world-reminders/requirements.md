# 007 时间、天气与提醒｜需求

依赖 001/002/服务宿主；PRD 12–13、28。开发见 [development](development.md)。

| 编号 | 需求 |
|---|---|
| WR-01 | 时间含时区，有效性明确；昼夜和提醒使用正确时间 |
| WR-02 | 城市由用户设置，天气轻量展示，过期有标记 |
| WR-03 | 天气影响场景而非成为独立插件 |
| WR-04 | 对话或控制中心可创建一次性提醒；时间模糊时澄清 |
| WR-05 | 提醒到时设备本地触发，A 完成、B 稍后 10 分钟 |
| WR-06 | 未同步到设备不能声称断网时设备一定会提醒 |
| WR-07 | 重启、离线完成、修改时间、删除都不导致重复响铃 |
| WR-08 | 提醒可在控制中心查看、改时间、取消；设备显示近期一条 |

建议临近提醒为未来 30 分钟；多条显示最近一条，可进详情看列表。到点多条按 due_at 排队，不叠加播放。角色睡眠不等于关闭已设置提醒；夜间是否静音由用户设置。

默认只做一次性提醒，重复规则另行扩展。“明天早一点”需确认具体时间；“今晚七点”已过时需确认是否次日。断网设备可执行已保存提醒，但不支持新的自然语言解析。

天气失败保留最近值，超过 2 小时显示“较早天气”，超过 24 小时 Home 隐藏温度；不根据过期天气声称实时下雨。验收涵盖时区切换、RTC 无效、关机错过提醒和设备未同步。
