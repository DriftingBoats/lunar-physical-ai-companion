# 006 自主生活与小旅行｜需求

目的：无需喂养也持续有生活感。依赖 002/003/007/008/服务宿主；PRD 9–11。开发见 [development](development.md)。

| 编号 | 需求 |
|---|---|
| LF-01 | 本地 Idle / Play / Observe / Sleep 状态，无网络也变化 |
| LF-02 | 作息受时间与用户配置影响，无断签惩罚、精力扣减 |
| LF-03 | 小旅行是生活事件，不加入插件菜单 |
| LF-04 | 旅行由结构化规则限制，AI 动态生成去向、观察、纪念物、短评 |
| LF-05 | 有出发、空房间、返程表现；设备不会因角色出门而拒绝对话 |
| LF-06 | 故事使用 fictional_trip 来源，回忆卡标“小旅行故事” |
| LF-07 | 纪念物用有限模板，语义可变，关联唯一旅行事件 |
| LF-08 | 用户数日未使用不累积惩罚，不批量补生成故事 |

建议默认：22:30–08:00 睡眠，用户可改；不跨入即将到来的提醒或正在录音时出发。每天最多一次生成尝试窗口、成功旅行间隔至少 24 小时，失败最多两次生成调用后结束当日尝试。初始频率是待试用调整值。

旅行应与当前角色设定一致，但并不把 Lunar 设定固定到业务代码。真实天气是背景输入，不证明故事真实发生；不得把“它去过”变成“用户和它一起去过”。

验收：离线两小时、跳过数天再启动、生成失败、连续五次旅行、出门时讲话、换角色时旅行未结束，以及来源追问。
