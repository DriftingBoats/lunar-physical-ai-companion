# M13 iPhone 记忆中心｜需求

> **可选历史方案，非当前主线。用户最终选择云端主记忆与 PWA；以下仅在未来明确重启 iPhone 主库路线时使用。**

用户确认：iPhone 负责完整记忆管理和检索。依赖 M08 数据规则、M04 对话与通信协议。开发见 [development](development.md)，流程见 [iPhone 方案](../../10-iPhone记忆中心与检索.md)。

| 编号 | 需求 | 验收 |
|---|---|---|
| IP-01 | 手机为记忆唯一主本 | 一万条数据在手机，Core 不接收全库 |
| IP-02 | 按来源搜索，编辑、删除、收藏、查看证据 | 三类记录不混淆 |
| IP-03 | 接收设备事件并持久化确认 | 重传不重复，提交前断电不假 ACK |
| IP-04 | BLE 按需检索，最多 5 条/8KiB | 超限不发送，Core 不无限接收 |
| IP-05 | 手机不可用时 Core 缓存回退 | 对话不被完整检索绑死 |
| IP-06 | 删除优先同步，显示未应用状态 | 离线旧缓存不假称已清理 |
| IP-07 | 备份恢复、换手机、换设备 | 来源、版本和逻辑身份保持 |
| IP-08 | 权限拒绝和后台限制有明确状态 | 用户能知道连接和同步是否有效 |

首版不要求手机识别或合成语音，不中转录音，不要求用手机跑大型模型；后台检索不承诺全天即时。需要原生 App，普通手机网页不作为长期记忆唯一主库和可靠后台蓝牙服务。

性能目标需实测：前台小查询通常在 2 秒预算内完成；不可用快速回退；Core 资源随缓存上限固定，不随主库条数线性增长。
