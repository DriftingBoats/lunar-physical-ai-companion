# M08 记忆与共同经历｜需求

依赖事件来源、存储与同步；PRD 19、24 及用户确认修订。开发见 [development](development.md)。

| 编号 | 需求 |
|---|---|
| ME-01 | 分 Profile、Shared Memory、Recent Context，非完整聊天日志 |
| ME-02 | 每条经历必须是 fictional_trip / shared_experience / user_reported 之一 |
| ME-03 | 设备轻量浏览，管理端支持搜索、来源筛选、编辑、删除 |
| ME-04 | 生成小旅行不能进入真实经历或用户事实 |
| ME-05 | AI 判断“值得保存”不改变真实性分类 |
| ME-06 | 换角色和换设备后保留当时来源和版本 |
| ME-07 | 删除后停止检索，离线缓存下次连接同步清除 |
| ME-08 | 无相关证据时坦诚不记得，不补造旅行、人物或地点 |

设备卡片显示日期、标题、短内容、来源标签；上下换记录、左右翻页、B 返回。空列表显示“还没有留下回忆”，不填充假真实记忆。初始缓存 100 条为建议默认。

用户手动保存的内容默认 user_reported；真实设备交互需事件依据。用户编辑内容时来源标签不悄悄消失；补充现实确认应新建有关联的用户自述或确认事实。

验收最重要的例子：一次中泰翻译可以保存为“一次中泰翻译”，未经说明不能保存为“我们在曼谷点餐成功”。
