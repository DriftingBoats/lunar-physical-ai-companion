# M10 PWA 管理端｜需求

用户确认管理端使用网页，可添加iPhone主屏幕，像mini app一样打开。依赖云记忆/配置API；不要求原生App、不常驻中转AI。开发见 [development](development.md)。

| 编号 | 页面/能力 | 需求 |
|---|---|---|
| CC-01 | 设备首页 | 连接、当前角色、电量、固件、最近同步、待应用设置 |
| CC-02 | Character | 人格Basic/Advanced、形象资源、声音选择与试听 |
| CC-03 | Brain | provider/model/音色/超时/预算，简单档位与高级配置 |
| CC-04 | Memory | Profile/经历/近期摘要，来源筛选、检索、编辑、删除、导出 |
| CC-05 | Plugins | 翻译等内置能力开关、语言组、允许的按键配置 |
| CC-06 | Device | 配网说明、时区城市、音量亮度、诊断、升级、备份恢复 |
| CC-07 | 提醒管理 | 一次性提醒新增编辑取消，显示是否已到设备 |
| CC-08 | 主屏幕 | 自定义图标名称、独立窗口、深层路由可刷新 |
| CC-09 | 离线草稿 | 明确未提交；恢复连接用户确认重试，不能假成功 |
| CC-10 | 会话和更新 | 退出清本地私密缓存，更新不吞掉编辑草稿 |
| CC-11 | 分层记忆与时间线 | 长期/短期/临时筛选；发生时间、有效期、记录时间分别可查看 |
| CC-12 | 重要性说明 | 分数、分项、理由、评分时间；用户可固定、调整保留或覆盖分数 |
| CC-13 | 我们之间 | 称呼、关系设定、互动边界、共同里程碑和可纠正推断，不展示养成等级 |
| CC-14 | 主动回忆 | 开关、勿扰/频率、不再提及列表；与Reminder独立 |
| CC-15 | 人格学习候选 | 区分核心人格与学习候选，接受才发布新preset版本 |

PWA首页不复制聊天。手机与电脑同一套数据，网页关闭后Core能继续对话、翻译、提醒与记忆查询。离线只能查看已明确缓存内容和本地草稿，浏览器缓存不是主库或可靠备份。

iPhone提供“分享→添加到主屏幕”的指引，不要求原生下载。首次设备配网走限时设备热点或USB，不能依赖Safari支持Web Bluetooth。

验收：iPhone Safari/主屏幕模式与电脑浏览器，完成登录、配对、改角色、删记忆、导出、离线草稿和版本更新。以上是需求，当前没有可安装网址。

## Ombre Brain 参考补充

记忆详情可展开必要原文依据与情绪主体；提供角色反思、低活跃旧事视图，并说明低活跃不代表删除。保持用户可纠正的关系/偏好界面。 共同约束见 [13 记忆实现方案](../../13-Ombre-Brain参考与记忆实现方案.md)。
