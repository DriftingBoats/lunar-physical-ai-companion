# M04 语音与对话｜开发

关联 [需求](requirements.md)。**主方案 Core 直连服务商，不调用项目自建 /audio-jobs。STT/LLM/TTS模型全部在外部服务器。** 具体适配见 [09](../../09-设备直连开发基线.md)。

## 状态与音频

IDLE→CAPTURING→UPLOADING_STT→MEMORY_QUERY→LLM_WAIT→TTS_WAIT→PLAYING→IDLE；任意活动态可取消或失败回IDLE。一次session绑定开始时角色版本。

录制前停播清队列；输入建议16kHz/mono/PCM16 WAV，20ms块640字节，最多20秒约625KiB。双麦数据由HAL正确混为单声道，不直接误读交错采样。低于200ms或明显静音提示重录，阈值实测，避免过滤轻声说话。

缓冲有界，网络工作不阻塞输入；松键只结束一次。上传用二进制流，除非所选服务要求否则不base64。实际采样和服务格式在适配层明确转换。

## 执行顺序

STT→云记忆查询最多2秒→来源受控结果或有限缓存→LLM→本地工具校验/持久化→准确回复文字→TTS→下载播放。

服务接口transcribe/reply/synthesize各有不同HTTP协议，由C++适配器处理。查询记忆通过本项目API，音频不经过记忆服务。provider精确URL、模型和音频编码选定后另写专项文档，不能假定所有兼容服务相同。

共享45秒绝对截止；阶段建议STT≤15秒、LLM≤20秒、TTS≤15秒，实际每步min(阶段预算,总剩余)，记忆等待包含在总预算中。TTS失败但文本成功可显示文字，重新合成由用户触发，不重复整个对话。

## 工具动作

首版允许reminder.create，参数title、due_at、timezone。时间不明先询问；Core验证并持久化后才可说已设置，同时将事件加入outbox同步。落盘失败不能播放假成功。翻译模式禁止执行工具。

LLM不能任意执行代码、请求URL或更改source_type。工具操作用event_id去重；跨重启保留执行记录。取消前已成功的动作保留，可查看；取消后未开始的动作不补执行。

## 取消与重试

B短按或Start取消，立即释放本地焦点；服务商已收到请求可能仍计费，不保证取消免费。所有回调匹配session_id，晚到不播放、不重发模型。对未知提交结果不无限自动重试；上传重试次数、幂等支持按provider官方协议定义。本地动作去重独立于服务商是否幂等。

## 测试

Mock各阶段成功与超时、空/假WAV、20秒上限、取消晚到、重复提醒、API429、记忆失败、TTS编码错误。真实设备记录20轮耗时与100次循环内存；讲话动画先按音量包络变化，不声称精确口型。正式Lunar音色另做试听验收。
