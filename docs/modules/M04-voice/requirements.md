# M04 语音与 AI 对话｜需求

依赖 M01/M02/M03/M14/M11，PRD 14、23。方案见 [development](development.md)。

## 用户流程

Home 长按 A→进入倾听→用户说话→松开 A→思考→文字和声音回复→回 Home。单次最多 20 秒为建议默认，达到上限自动结束且忽略本次按键后续释放；不做全天监听。

| 编号 | 需求 |
|---|---|
| VO-01 | Listening、Thinking、Speaking 状态反馈及时，可用 B 短按取消 |
| VO-02 | 空音频、超长录音、网络超时给简短反馈，能回 Home |
| VO-03 | 文本按角色设定生成；TTS 音色与语言由配置选择 |
| VO-04 | 用户主动打断播放后，新录音不录到上一句外放声 |
| VO-05 | AI 创建提醒必须经过结构校验和真实保存，不能口头假成功 |
| VO-06 | 返回的记忆保留来源，故事不被当作用户真实经历 |
| VO-07 | 手机关闭不影响设备直连后端的对话 |

断网时本地短语可反馈“现在连不上，等一会儿再试”；它不等于离线 AI 对话。云文字成功而 TTS 失败时保留文字并显示可重试声音，不要求重做整次对话。

验收：安静室内 20 轮短对话，记录识别、回复、播放与耗时；至少覆盖取消、超时、空音频、音量为零、提醒创建和故事追问。不将模型偶然正确视为全部功能通过。
