# M05 中泰翻译｜需求

依赖 M02/M04/外部 AI 服务；PRD 18。主方案为 Core 直连外部 AI，云端记忆独立，见 [直连路线](../../09-设备直连开发基线.md)。开发见 [development](development.md)。

| 编号 | 需求 |
|---|---|
| TR-01 | 从 Start 进入，A 长按中文→泰语，B 长按泰语→中文 |
| TR-02 | 译文优先，原文弱化显示，方向和历史序号占少量空间 |
| TR-03 | 成功后播放译文，A 短按或触摸播放图标可重播 |
| TR-04 | 上下浏览历史；左右翻长文页；Select 切换已配置语言组 |
| TR-05 | B 短按返回，Start 打开菜单；离开取消未完成任务 |
| TR-06 | 长文不静默截断，泰文声调与组合符号不重叠、不缺字 |
| TR-07 | 翻译保持原意，不加角色语气、笑话或虚构信息 |
| TR-08 | 断网可浏览已缓存历史；声音未缓存时明确不可回放 |

Select 只有一个语言组时显示当前组且不改变状态。长按 B 松开不能同时触发返回。数字、否定、人名和礼貌表达属于质量重点；不假定用户性别自动附加可能不适合的语尾。

翻译一次只需一次长按动作是核心目标，首次配对、联网、打开插件不计入单次录音动作。当前主方案手机不参与实时链路。

验收：各 20 句中泰文本及语音，包含问路、点单、数量、价格、否定、长句；由懂泰语的人核验关键意义与发音。仅“有返回文本”不算翻译质量通过。
