# M03 角色、形象、声音与资源｜需求

目的：通用配置，默认是 Lunar，方便以后换设定。依赖 M02、M14、M10；对应 PRD 本次约束、22、29。方案见 [development](development.md)。

| 编号 | 需求 | 验收 |
|---|---|---|
| CH-01 | 名称、身份、性格、说话风格、边界可配置 | 换一个测试预设，无须修改固件源代码 |
| CH-02 | Basic 与 Advanced 两种编辑方式 | 滑杆可转为结构化设置，高级字段保留 |
| CH-03 | 图片、动画、固定音效、TTS 音色关联到版本化预设 | 形象和声音配置可分别替换 |
| CH-04 | 原子切换、资源损坏回退 | 下载失败仍显示原角色，不半新半旧 |
| CH-05 | 历史保留原角色版本 | 旧旅行不被改写成新角色经历 |
| CH-06 | 同一设备只有一个活动预设 | 编辑草稿不影响正在对话的角色 |
| CH-07 | 核心人格、学习候选、当前状态分开 | 普通对话和记忆评分不能自动改写身份与基本边界 |
| CH-08 | 有自己的表达、偏好和自主行为，可温和表达不同意见 | 不机械迎合用户；不同情景下表达保持一致 |
| CH-09 | 角色自身故事与共同现实经历分别保留 | 换预设不认领旧角色亲历，学习候选可接受或拒绝 |

最低动作：idle、play、observe、sleep、wake、listen、think、speak、away、return、interact。可以共享基础帧，但对话状态要清楚。Lunar 的正式形象和声音依据用户认可的素材，当前概念图不是完整资源包。

人格与关系的积累方式见 [分层记忆规格](../../12-人格关系与分层记忆系统.md)。独立人格不要求改变通用可配置架构；PWA仍可明确发布新版本。

声音分固定短片段与动态 TTS；更换预设时可以使用库存音色。Lunar 动态音色需单独试听通过；语言不支持时清楚提示并让用户选择替代音色，不能把通用音色描述为已还原 Lunar。

用户自定义 System Prompt 可以改变角色行为风格，但不能绕过程序的身份验证、来源分类、提醒写入校验或世界规则。
