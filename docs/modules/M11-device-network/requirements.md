# M11 配网、设备管理、升级｜需求

依赖 M01/M02；PRD 26–29；开发见 [development](development.md)。推荐路线：设备直接连 AI，手机仅可选管理。

| 编号 | 需求 |
|---|---|
| DN-01 | 已保存 Wi-Fi 自动连接，失败进入可用离线状态 |
| DN-02 | 首次可 USB 配置，后续设备提供限时配网与管理入口 |
| DN-03 | 区分 Wi-Fi 断开、互联网不可用、AI 不可用，不能只有一个模糊在线状态 |
| DN-04 | 离线仍有 Home、作息、已保存提醒、缓存回忆和基本互动 |
| DN-05 | 配置音量、亮度、时区、城市；电量未知不假显示百分比 |
| DN-06 | 备份和恢复包含角色引用、记忆、提醒；更换设备不丢逻辑身份 |
| DN-07 | 固件升级校验型号和完整性，有恢复途径；资源包升级单独管理 |
| DN-08 | 清除设备可只清凭据或同时清本地数据，执行前显示范围 |

P2 蜂窝网络是新增硬件阶段，本组合没有原生 4G/eSIM。Wi-Fi 热点可以是临时外出联网方式，热点手机只供网络不处理 AI；个人热点能否自动保持连接须实测。

验收：错误 Wi-Fi 密码、断网、重启、证书错误、管理会话结束、升级断电、资源损坏、旧备份恢复。没有实测回滚不能宣称 OTA 安全可靠。
