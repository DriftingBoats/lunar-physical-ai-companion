# M14 云端记忆服务｜需求（主方案）

用户最终确认云端主库。依赖 M08 来源规则、M04 对话和 M10 管理界面。开发见 [development](development.md)。

| 编号 | 需求 | 验收 |
|---|---|---|
| CM-01 | 保存完整记忆及索引 | 一万条测试记录下设备缓存仍有界 |
| CM-02 | 按来源、权限、关键词/日期检索 | 每次最多5条/8KiB，禁止跨用户 |
| CM-03 | 设备事件事务归档、幂等 ACK | 重复和断连不重复记忆 |
| CM-04 | 管理端查看编辑删除、备份恢复 | 删除不因旧缓存/旧备份复活 |
| CM-05 | 查询不可用时设备回退 | 2秒建议截止，不影响本地生活 |
| CM-06 | 设备独立认证、撤销和换机 | 不用手机常驻，不能拿ID当密码 |
| CM-07 | 不要求音频经过记忆服务 | 仅传必要文字、事件与元数据 |
| CM-08 | 资源用量与失败可观测 | 有查询延迟、存储与费用计数 |

首版不要求 embedding 或复杂 AI 记忆代理；来源准确、可以删除、可以恢复和响应有界优先。云不可用仍能用缓存；新云端记忆不可获取，不能假称全历史在线。

新增核心范围：三层保留与时间有效性、可解释的重要性评分、关系摘要和主动回忆候选。评分/整理使用异步云任务，不中转设备音频，不进入2秒查询等待；具体规则见 [分层记忆规格](../../12-人格关系与分层记忆系统.md)。

## Ombre Brain 参考补充

增加必要原文证据、可纠正的情绪归属、独立重提计数及反思整理。禁止用查询次数增加重要性或事实置信。支持证据删除级联，记忆原文不自动推送到代码GitHub库。 共同约束见 [13 记忆实现方案](../../13-Ombre-Brain参考与记忆实现方案.md)。
