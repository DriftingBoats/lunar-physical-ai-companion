# M14 云端记忆服务｜开发

关联 [需求](requirements.md)，实现基线见 [11](../../11-云端记忆服务开发基线.md)，端点以 [04](../../04-接口契约.md) 为准。

## 1. 项目结构与部署

建议目录 memory-service/functions、memory-service/migrations、memory-service/tests；函数 TypeScript，数据库 PostgreSQL，身份托管。先建立本地 Mock API 和契约，再在选定托管服务创建开发环境，运行迁移与权限测试。当前不实际创建云账号、部署或产生费用。

数据库迁移包括表、唯一键、外键、删除约束、索引和权限，不能只在网页控制台手改而没有脚本。发布时先迁移兼容字段，再更新函数；破坏性迁移先备份且验证回滚。

## 2. 认证层

管理用户身份由托管会话校验；设备 token 存哈希，通过绑定表解析 companion，令牌可撤销轮换。设备不能自行选择其他用户数据范围。配对 code 限时、限尝试、一次有效、实体确认；绑定完成撤销临时配对权限。

所有查询、修改、导出都加 owner 与 companion 限制；service role 仅服务端。对匿名、用户A、用户B、设备A分别测试查改删。数据库权限配置与函数范围检查同时存在，不假定服务端密钥自动提供用户隔离。

## 3. 写入与同步

events.push 验证类型、source_type、长度、角色版本、时间格式；在事务内插事件、记忆和 sync change。event_id 唯一；重复输入返回既有 ACK，不再次产生记录。sync 游标基于提交序列，删除优先，批量返回有固定字节上限。

设备保留 outbox 直到 accepted；一批部分失败逐项报告。确认信息丢失时同一 event_id 重传仍安全。数据库无法提交时不得回复“成功”。

## 4. 检索

先权限→deleted_at为空→来源 scope→关键词/标签/日期评分→裁剪结果。中文使用验证后的方案，不默认依靠英文全文配置；以“快递”“曼谷”“上次翻译”等测试。向量检索后续增加，过滤条件和证据字段不变。

响应有 index_revision、records、retrieval_status，每条 source_type、evidence IDs、角色版本。source_type=fictional_trip 永远不用于现实事实 Profile；无结果返回空，不生成假回忆。缓存带 revision，设备拒绝旧 epoch 和超限响应。

## 5. 删除与派生数据

主表删除墓碑与 deletion_ledger 在事务内提交，查询立即过滤；异步清索引、摘要、关联媒体。重建索引及备份恢复同样应用删除标识。删除原始证据时重新评估仅依赖它的 Profile 项。

## 6. 首轮交付与验收

迁移脚本、函数、测试、Mock、环境变量示例、部署和导出恢复手册；不要提交服务密钥。测试1万条数据、跨用户、乱序重传、删除同步、游标过期、配对超时、数据库故障、服务冷启动、缓存回退和真实地区网络。
