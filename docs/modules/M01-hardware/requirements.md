# M01 硬件与驱动｜需求

范围：让选定三件硬件稳定工作，为其他模块提供真实输入输出。依赖：实物到手；PRD 5、15、26、33。开发方案见 [development](development.md)。

## 功能需求

| 编号 | 要求 | 完成标准 |
|---|---|---|
| HW-01 | 识别主控与两个扩展板实际型号 | 留存 SKU、版本、装配记录 |
| HW-02 | 显示和触摸 | 四角绘制正确，触摸坐标匹配实际屏幕方向 |
| HW-03 | 八键按下与松开 | 每键独立读出，同时按键不被误识别 |
| HW-04 | 录音与扬声器 | 安静室内录一句话可回放，无明显削波和持续底噪 |
| HW-05 | 网络、RTC 与存储 | Wi-Fi 可连接；时钟有效性可判断；存储写入重启后可读 |
| HW-06 | 底座供电与充电 | 核验上电、拔 USB、开关、充电；不异常复位 |
| HW-07 | 故障降级 | SD 缺失仍显示 Home；电量未知显示未知 |

主控规格以 [官方资料](https://docs.m5stack.com/en/core/StackChan_Core) 为准；Bottom3 [标称 600mAh](https://docs.m5stack.com/en/faces/Faces_Bottom3)。不承诺未经测试的整机重量、尺寸或连续工作时长。RGB 非核心功能，首版默认关闭以减少功耗。

## 不在本模块做

不开发摄像头识别、舵机动作、定制 PCB 或蜂窝网络；也不把原厂 App 的兼容性当成本项目自定义固件的兼容保证。

## 验收操作

依次验证屏幕→触摸→八键→音频→网络→存储→供电，最后联合运行。录下组合使用 30 分钟是否重启、按键是否漏读。未拿到设备前所有结果只能写“待实机验证”。
