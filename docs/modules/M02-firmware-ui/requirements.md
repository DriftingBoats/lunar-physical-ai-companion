# M02 固件、屏幕与按键｜需求

目的：小屏和按键形成稳定、低负担的生活入口。依赖 M01、M03；PRD 6–8、14–18、28。方案见 [development](development.md)。

## 页面需求

| 编号 | 页面 | 需求 |
|---|---|---|
| UI-01 | Home | 角色为主；时间、电量极简；天气和临近提醒条件显示 |
| UI-02 | 对话覆盖层 | Listening / Thinking / Speaking，可取消，结束回 Home |
| UI-03 | Start 菜单 | 翻译、回忆、设置；上下选择、A 确认、B 返回 |
| UI-04 | 简要上下文 | Select 打开当天状态与网络简况，再按或 B 关闭 |
| UI-05 | 翻译与回忆 | 见 M05/M08；页面离开后不继续播放或处理旧输入 |
| UI-06 | 设置 | 音量、亮度、网络状态、配对、设备信息；复杂管理去手机 |

不在 Home 加常驻聊天按钮、心情数值、等级、插件宫格。触摸角色等价于快速互动，不默认启动持续监听。

## 按键需求

建议短按定义为释放前未超过 350ms；长按在达到 350ms 时开始，释放时结束。一次长按绝不同时触发短按。只有方向键导航可自动重复，A/B 不自动重复。

Home A 短按互动、长按说话；B 处理当前事件或无动作。翻译页 A/B 长按分别为中→泰、泰→中；B 短按返回。所有页面 Start 返回插件菜单；录音和播放先取消。设置和提醒覆盖层内 A/B 按当前操作含义执行，不开启讲话。

## 验收

UI-07：长按松手不误触菜单确认；按住键切页，新页面不继承按下状态。

UI-08：网络超时仍能返回 Home；提醒与录音争用时不抢占录音数据，按统一优先级排队。

UI-09：中文无方框；长文可分页，触摸目标不互相重叠，离线图标不挡住角色。
