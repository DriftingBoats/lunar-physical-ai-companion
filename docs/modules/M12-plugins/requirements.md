# M12 插件框架｜需求

依赖 M02/M03，PRD 17、25、30。开发见 [development](development.md)。

| 编号 | 需求 |
|---|---|
| PL-01 | 首版内置翻译、回忆；设置为系统入口 |
| PL-02 | 天气、提醒、对话、小旅行不塞进插件菜单 |
| PL-03 | 管理界面能开关插件和配置语言组，关闭后菜单更新 |
| PL-04 | 插件遵循方向导航、A 主操作、B 返回和 Start 菜单的语义 |
| PL-05 | 插件声明版本、需要的资源和能力，设备不支持时给出原因 |
| PL-06 | 当前插件被关闭时取消任务并安全回 Home |

“可扩展”指代码模块与配置可扩展，不做在线插件商店或任意下载执行脚本。首版新增插件仍需代码审查与固件更新。系统设置不能被关闭，关键恢复按键不能被自定义映射覆盖。

验收：关闭翻译后不显示入口；重新开启配置仍在；播放中关闭释放音频；非法按键映射拒绝；无网络时插件显示不可用的具体能力而非整机报错。
