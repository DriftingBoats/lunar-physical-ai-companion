## 性能目标（待测）

按键反馈通常≤100ms，动画先10–15fps。20次短句松键到首段播放记录p50/p95，初始目标≤5秒/10秒，总等待45秒；记忆查询共享其中最多2秒，不额外叠加无限等待。分别测STT、记忆、LLM、TTS和下载，找真实瓶颈。

云查询测冷/热响应、区域可达性；Core100次语音和同步检查最低heap与泄漏；记录实际电池时长、亮度、音量和调用频率，不宣称未测续航。PWA测360/390/768px及桌面、Safari主屏幕与普通浏览器。

## 工具与执行

规则主机测试：输入、提醒、来源和幂等；API测试：权限、CRUD、同步、备份；Mock端到端：错误注入；实机：音频、TLS、字体、掉电。正式角色和音色需用户认可，占位资源不算完成。

## 部署顺序

1. 固定固件依赖、provider与协议，Mock和本机测试通过。
2. 选择托管记忆开发项目和区域，配置身份、迁移、权限与函数；不把管理密钥发到设备。
3. 部署PWA HTTPS静态产物和同源API会话入口，配置manifest、图标、service worker、路由回退。
4. 核验生产与开发数据分离，开启预算/用量记录，测试导出和恢复。
5. 先一台设备灰度，手机PWA真实安装测试；固件先USB，OTA后做回滚演练。
6. 七天试用，报告未通过项后再决定日常发布。

生产不能使用Vite dev server，service worker不能无差别缓存私密API和POST。现阶段没有发布网址，本次不创建收费服务或部署。

## 运行维护

request_id贯穿，日志默认不留密钥或完整记忆。PWA显示device last_seen、desired/applied、缓存/同步状态。查不出记忆先看API及索引版本；只有字无声音看TTS格式和播放；配置没变看设备ACK。

备份必须实际恢复一次才算通过。云费用按数据库/函数/出口/可选embedding记录，AI费用另算；provider缺usage时标估算。预算超限停止新付费请求，本地提醒继续。
