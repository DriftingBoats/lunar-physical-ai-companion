## 已核对的官方资料

1. [StackChan Core 规格](https://docs.m5stack.com/en/core/StackChan_Core)：C156、ESP32-S3、16MB Flash、8MB PSRAM、320×240 屏幕及音频外设；原生无线为 Wi-Fi/BLE。不能据此推断整机续航或 Faces 组合已测试。
2. [Faces Bottom3 规格](https://docs.m5stack.com/en/faces/Faces_Bottom3)：A168、600mAh 电池、充电底座、M5-Bus；兼容列表列 Core 系列，具体 StackChan Core 组合仍需验证。
3. [Faces Gamepad3 规格](https://docs.m5stack.com/en/faces/Faces_Gamepad3)：A004-V3，八键，I²C 地址 0x08。
4. [Gamepad3 Arduino 示例](https://docs.m5stack.com/en/arduino/projects/faces/faces_gamepad3)：使用 M5Faces_Gamepad3 和 M5.In_I2C。不要照搬旧代 Faces 的库和接线常量。
5. [StackChan 显示示例](https://docs.m5stack.com/en/arduino/stackchan/display)：M5CoreS3 板选项；页面列板包 ≥3.2.2、M5Unified ≥0.2.11、M5GFX ≥0.2.18，最终测试版本另记。
6. [StackChan 麦克风示例](https://docs.m5stack.com/en/arduino/stackchan/mic)：用于验证录音基础链路，不等于已接云语音。
7. [Espressif OTA](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-reference/system/ota.html)：双 OTA 槽、OTA 数据分区及启动验证机制。Arduino 构建是否开启回滚需单独验证。
8. [FastAPI 入门](https://fastapi.tiangolo.com/tutorial/first-steps/)：后端路由与开发运行方式。
9. [Vite 入门](https://vite.dev/guide/)：网页开发环境和 Node 版本要求。
10. [HarfBuzz 排版说明](https://harfbuzz.github.io/what-is-harfbuzz.html)：字符到字形定位的 shaping 概念；泰文正确显示需要字体与排版链路共同验证。
