# 三端接口契约 v0.1

> 可选历史方案，非当前主线。请以 docs/README.md 和当前总架构为准；这里保留早期全功能后端设计，未实现。

本文定义项目自己的协议，不是 M5Stack 或某家 AI 服务的现有 API。路径和字段需要在实现阶段生成 OpenAPI，并由契约测试验证。业务模块不得各自发明同名不同义字段。

## 1. 公共约定

- 前缀 `/api/v1`；JSON 为 UTF-8，时间为带时区的 ISO 8601。存储用 UTC，展示使用 IANA 时区，例如 Asia/Shanghai。
- ID 是不透明字符串，示例 `job_demo_01` 不代表算法；生产使用随机 UUID。所有资源带所属用户或 companion，查询从认证身份限定范围。
- 设备使用可撤销的 Bearer token；网页使用后端会话 Cookie（HttpOnly、Secure、SameSite）及写请求 CSRF 校验。device_id 不能代替认证。
- 可重复提交的写请求带 `Idempotency-Key`，同一账号、路由、键及相同请求返回相同结果；同键不同内容返回 409。至少保留 7 天，长期事件另有唯一 event_id。
- 版本更新带 `base_revision`，冲突返回 409 及最新版本，不静默覆盖。
- 列表使用 `cursor` 和 `limit`，默认 20，最大 100；响应有 `items`、`next_cursor`。
- 成功的普通 JSON 使用 `{"data": {...}, "request_id": "..."}`；任务创建返回 HTTP 202。204 删除没有响应体。

统一错误示例：

```json
{"error":{"code":"PROVIDER_TIMEOUT","message":"回复超时，请重试","retryable":true},"request_id":"req_demo_01"}
```

| HTTP | code 示例 | 处理 |
|---|---|---|
| 400 / 422 | INVALID_INPUT / AUDIO_TOO_LONG | 修正输入，不自动重发 |
| 401 / 403 | TOKEN_EXPIRED / FORBIDDEN | 刷新或重新配对；不暴露其他用户资源 |
| 409 | REVISION_CONFLICT / IDEMPOTENCY_CONFLICT | 拉取最新并提示冲突 |
| 413 | PAYLOAD_TOO_LARGE | 拒绝过大音频、资源包 |
| 429 | RATE_LIMITED / BUDGET_EXCEEDED | 尊重 Retry-After；预算超限停止付费调用 |
| 503 / 504 | PROVIDER_UNAVAILABLE / PROVIDER_TIMEOUT | 可由用户重试，设备仍可本地生活 |

## 2. 配对与身份

设备出厂或开发注入独立 bootstrap secret（开发阶段经 USB 写入、不提交仓库）。它只能建立待配对请求，不能读取用户数据。

| 方法与路径 | 调用方 | 输入 / 输出 |
|---|---|---|
| POST /pairing/start | 设备、bootstrap 认证 | 设备型号和随机 nonce → pair_id、8 位一次性 code、expires_at |
| POST /pairing/claim | 已登录网页 | code → claim_id；设备显示待绑定账号的脱敏名称 |
| GET /pairing/{pair_id} | 发起设备 | 查看是否有人认领 |
| POST /pairing/{pair_id}/confirm | 发起设备 | 用户实体 A 确认 → 创建绑定、返回 device token 和 companion_id |
| DELETE /devices/{id}/binding | 所有者网页 | 撤销令牌并解绑；云记忆保留，除非另做删除 |

code 5 分钟失效，单次有效，限速 5 次失败后冻结该配对尝试；实体确认等待 60 秒后取消。网页永远拿不到设备密钥。网页登录首版采用服务端预建单用户账号、密码散列与会话；公网部署必须更改初始凭据，禁用公开注册，后续再扩展身份服务。

## 3. 对话和翻译：同一异步任务模型

`POST /audio-jobs`，设备 token + Idempotency-Key；multipart 表单：`audio`（WAV）、`meta`（JSON 字符串）。

```json
{
  "client_event_id":"evt_demo_01",
  "mode":"conversation",
  "character_preset_id":"lunar",
  "character_version":1,
  "config_revision":3,
  "source_language":"zh-CN",
  "target_language":null,
  "captured_at":"2026-09-09T09:00:00Z"
}
```

`mode` 仅 conversation 或 translation；translation 必须填 source_language 和 target_language。服务端校验角色版本属于该 companion，不能任意指定其他账号资源。音频必须单声道 PCM16、16kHz、有效采样最长 20 秒，上传体最大 1MiB；不匹配返回 422。

创建响应 `data={job_id,status:"queued"}`。`GET /jobs/{id}` 返回 queued / processing / succeeded / failed / cancelled；轮询建议 1 秒，等待上限 45 秒。`DELETE /jobs/{id}` 请求取消，未完成时置 cancelled；已完成仍可返回其终态，设备本地必须丢弃已取消会话的晚到结果。

成功结果字段：

```json
{
  "job_id":"job_demo_01",
  "status":"succeeded",
  "result":{
    "source_text":"你好",
    "text":"你好，今天过得怎么样？",
    "language":"zh-CN",
    "audio_asset_ids":["asset_demo_01"],
    "text_page_asset_ids":[],
    "actions":[],
    "character_version":1
  }
}
```

翻译的 `text` 仅译文，不能添加角色寒暄。`actions` 由后端已执行的业务结果构建，格式 `{type,resource_id,status}`，提醒状态可为 stored_cloud / applied_device；LLM 输出的“已完成”不能直接透传成此字段。媒体正在生成时可保持 processing；TTS 失败允许 succeeded 且 `audio_asset_ids=[]`，附 `warnings:["TTS_UNAVAILABLE"]`。

## 4. 媒体

`GET /assets/{id}/manifest` 返回 content_type、bytes、sha256、expires_at 和带认证的下载路径；`GET /assets/{id}/content` 下载本人可访问的内容。允许 Range 续传；过期返回 410，不能用长期公开 URL。PCM 音频按句拆段、逐段播放；译文图片是约定尺寸的 PNG 页面，设备下载解码后只保留必要页。

## 5. 配置、模型与插件

| 方法与路径 | 输入 / 输出 |
|---|---|
| GET /companions/{id}/config | 当前 desired_revision、角色版本、生活设置、brain profile、插件、设备偏好 |
| PUT /companions/{id}/config | base_revision + 完整可编辑配置 → 新 desired_revision |
| GET /devices/{id}/config | 设备应应用的完整快照及资源清单 |
| POST /devices/{id}/config-ack | revision、status=applied/rejected、错误原因；applied 后才显示生效 |
| GET /character-presets | 当前用户可用的版本化预设列表 |
| POST /character-presets | manifest 和设置 → 待验证预设版本；媒体单独上传受限接口 |
| POST /provider-profiles | provider、model、secret（仅写）等 → profile_id；读取仅掩码 |
| POST /provider-profiles/{id}/test | capability → 连通性、延迟与失败原因 |
| GET /plugins | 内置插件 manifest、启用状态、支持协议 |

角色资源未完整校验前不能 ack applied；失败保留上一个版本。provider endpoint 自定义仅管理员设置、验证协议和目的地址，禁止任意请求内网地址。网页普通用户只能选已登记 profile。

## 6. 天气、提醒、记忆

| 方法与路径 | 约定 |
|---|---|
| GET /companions/{id}/weather | city、temperature_c、condition、observed_at、fetched_at、stale |
| GET /companions/{id}/reminders | 状态过滤、分页列表 |
| POST /companions/{id}/reminders | title、due_at、timezone、client_event_id；v1 一次性提醒 |
| PATCH /reminders/{id} | base_revision、操作 complete/snooze/edit/cancel；返回新 revision |
| GET /companions/{id}/memories | source_type、query、cursor；保留来源字段 |
| POST /companions/{id}/memories | 用户手动保存只能 user_reported；设备真实事件走 sync 验证 |
| PATCH /memories/{id} | base_revision、title、content；source_type 不可变 |
| DELETE /memories/{id} | 生成删除墓碑，停止检索并级联派生缓存失效 |
| GET /companions/{id}/profile | 用户事实条目及证据引用 |
| POST /companions/{id}/profile | 用户明确输入的事实 |
| PATCH /profile/{id} 或 DELETE /profile/{id} | 版本化修改或删除 |
| GET /companions/{id}/recent-context | 可查看的近期摘要及来源 |
| DELETE /companions/{id}/recent-context | 清空并禁止从已删除数据重新生成 |

所有资源 ID 的访问都从 token 所属 companion 校验。小旅行生成由后端受控任务触发，不给客户端一个可绕过世界规则的任意生成入口。

## 7. 设备同步

`POST /devices/{id}/sync`，输入：

```json
{"cursor":null,"config_revision":3,"events":[{"event_id":"evt_demo_02","type":"reminder.complete","occurred_at":"2026-09-09T11:00:00Z","payload":{"reminder_id":"rem_demo_01","base_revision":1}}]}
```

返回 `accepted_event_ids`、`rejected_events`（含可重试标志）、`changes`、`next_cursor`、`server_time`。change 格式 `{entity,id,revision,operation:"upsert|delete",data}`；delete 的 data 可为 null。只有逐项持久化成功后才确认 accepted。

设备先将 changes 原子写入本地，再提交游标；网络中断可重新获取同批。cursor 过期返回 `SYNC_RESET_REQUIRED`，设备保留 outbox，重新拉快照后重放未确认操作；墓碑和冲突规则见数据模型。

`POST /devices/{id}/heartbeat` 上报 firmware_version、capabilities、battery（可 null）、free_heap、applied_revision、network；默认 60 秒一次，网页超过 3 分钟未收到显示离线及最后上报时间。

## 8. 旅行、升级、备份补充接口

- `POST /devices/{id}/trip-plan`：携带本地 eligible 状态及角色版本，后端校验冷却和世界规则；返回 accepted trip_id 或 skipped。相同计划 event_id 不重复收费生成。
- `GET /trips/{id}`：planned / generating / ready / failed，ready 带未来 return_at 和完整来源事件。设备确认接收后才进入 Away。
- `GET /devices/{id}/release`：适配 hardware_id 的版本清单；下载通过 assets，升级结果通过 sync 上报。
- `POST /companions/{id}/exports`：产生带 schema_version 的配置与记忆备份任务；GET /jobs/{id} 查看结果。
- `POST /companions/{id}/imports/preview`：上传备份、校验格式，返回冲突和影响数量；`POST /imports/{id}/apply` 明确执行恢复。凭据不从备份恢复。

接口契约验收：上传超限、跨用户访问、重复事件、旧 revision、取消后晚到响应、配置未 ack、游标过期必须有测试。未来流式音频可增加独立协议版本，不改变本协议字段语义。
