# 开发路线与任务清单

主路线：Core 直连 AI＋云端记忆＋PWA。以下全部待完成；阶段 M0–M7 与模块 M01–M14 为不同编号。

| 阶段 | 内容 | 通过标准 |
|---|---|---|
| M0 | 硬件、录音播放、TLS、泰文显示可行性 | 例程与问题记录明确 |
| M1 | 离线 Home、输入、角色资源、时间和提醒基础 | 断网2小时，重启可恢复 |
| M2 | Core 直连 STT/LLM/TTS | 20次对话、超时取消、内存记录 |
| M3 | 云记忆 API、认证、缓存同步 | 1万条测试库、权限与来源隔离、超时回退 |
| M4 | PWA 管理、配对、角色/记忆设置 | iPhone主屏幕启动，关闭网页设备继续工作 |
| M5 | 中泰翻译、天气、旅行与完整记忆对话 | 质量集、来源与离线用例通过 |
| M6 | 正式角色、备份、设备管理、有线恢复和OTA | 损坏资源、恢复和升级演练通过 |
| M7 | 7天试用；蜂窝与扩展评审 | 延迟、稳定性、功耗与体验有记录 |

### 记忆核心任务（在 T05–T09 内完成，不推迟到 T13）

- [ ] TM01：分层字段、事件时间/有效时间、来源与主体模型；安全迁移，不错误过期旧数据。
- [ ] TM02：评分分项与程序计算、异步整理、升级/过期、重复证据去重和依赖删除。
- [ ] TM03：关系摘要与学习候选，PWA纠正/接受流程，验证核心人格不自动漂移。
- [ ] TM04：时间感知检索、重要性/相关性分离、2秒有界返回与缓存。
- [ ] TM05：对话联想与空闲主动回忆、在线校验、焦点/频率控制、幂等回执。
- [ ] TM06：PWA分层时间线、分数理由、固定/禁提/删除控制；执行MEM-01至MEM-16。

每项交付代码、实际运行步骤、锁定版本、成功/失败测试、未完成项。Mock、占位素材、文档完成不能代替真实服务、正式角色和硬件验收。

开始不必买服务器：T00–T03 可在电脑/设备上完成，记忆接口用Mock。T04选定托管服务后才配置开发项目和预算；本次文档工作不创建收费服务。当前不需要Mac或原生iOS开发。
