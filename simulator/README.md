# 首屏模拟器

当前以 [Home对齐记录](ALIGNMENT.md) 为实现状态依据。默认自动生活：22:30–08:00睡眠，空闲动作每30–180秒调度；右侧手动动作与天气仅为测试输入。`life.js` 是离线规则，`character.js` 是独立版本化中性占位形象及动作绘制；原灰发像素角色已经移除。正式资源包仍待认可原稿与后续实现。

## 外壳比例依据

- [StackChan Core C156](https://docs.m5stack.com/en/core/StackChan_Core)：54 × 54 × 15.5 mm，2.0 英寸、320 × 240 屏幕。
- [Faces Bottom3 A168](https://docs.m5stack.com/en/faces/Faces_Bottom3)：108 × 54 × 12.5 mm，支持第一代和第三代 Faces 面板。
- [Faces Gamepad3 A004-V3](https://docs.m5stack.com/en/faces/Faces_Gamepad3)：57.0 × 54.1 × 10.7 mm（独立零件包络），八键布局参考官方三代正视尺寸图，已纠正初代型号。

正视图以底座 54:108 和上方 Core 54:54 为基准，下半部分为面板可见区域示意；不把各零件的包络尺寸直接相加为装配尺寸。屏幕名义显示区按 2.0 英寸与 4:3 推算为约 40.64 × 30.48 mm。按键中心、传感器位置及装配遮挡按照片/官方链接尺寸图近似，不是装配 CAD 或开孔模板。浏览器等比例放大显示，不保证显示器上的物理毫米；完整装配尺寸仍待实机核验。CSS 位于 `hardware.css`，四向键仅提供输入反馈。

设备尚未到手时，在电脑上验证 M02 Home 的 320×240 逻辑布局和交互。无需安装第三方依赖，使用 Node.js 20 或更新版本。

```powershell
cd D:\stackS3\lunar-physical-ai-companion\simulator
npm start
```

浏览器打开 http://127.0.0.1:18743 。运行 `npm test` 验证长按边界、取消、离线回退和生活状态保留。

鼠标点击角色或短按 A 互动；A 按住 350ms 进入模拟倾听，松开后模拟思考和回答；B 取消。键盘 A/B、Enter（Start）、S（Select）对应设备按键。Start 当前仅为功能占位，Select 显示模拟状态。右侧调整生活状态、昼夜、电量、离线与提醒；提醒在对话结束后恢复显示。

`state.js` 是独立于 DOM 的交互模型，`app.js` 绘制场景并提供模拟输入，未来固件按相同事件语义对接；当前 JavaScript 不能直接作为固件运行。像素角色由画布绘制，为可替换的占位形象。未使用麦克风，未接入天气、真实提醒调度、云服务或硬件。系统字体只用于电脑预览，中文字体打包、去抖、实体按键及触摸、性能和功耗均待固件实现与实机验证。
