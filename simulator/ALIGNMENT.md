# Home 文档对齐记录

## 外观校准补充

对照 C156 官方产品页第五张正视照片及 A004-V3 正视尺寸图：屏幕开口按名义75.26%面宽、上缘约21.3%面高；摄像头回到水平中心，两传感器位于右侧，微小开孔分列两边。四向键收紧中心间隙，A/B/Select/Start直径调整为约9.6%面宽，标签与塑料/玻璃边缘重新绘制。底座边缘与模块接缝提供CSS示意，侧倾视图仅展示层次，不声称装配厚度精确。未测量的比例仍为照片估算。

照片来源：[StackChan Core](https://docs.m5stack.com/en/core/StackChan_Core)、[Gamepad3](https://docs.m5stack.com/en/faces/Faces_Gamepad3)、[Bottom3](https://docs.m5stack.com/en/faces/Faces_Bottom3)。

本次范围是电脑 Home 模拟器，不代表 M01–M06 整体交付。

| 依据 | 当前实现 | 剩余边界 |
|---|---|---|
| PRD 6–8 / UI-01 | 320×240 生活场景；极简时间电量，天气未知隐藏，临近提醒独占底部32px | 中文嵌入字体、实机性能待验证 |
| LF-01/02、M06 §1 | 默认自动生活，固定种子，30–180秒切换，22:30–08:00跨午夜睡眠；未知时钟安全idle；交互暂时占用 | 作息目前可通过引擎参数配置，尚无设置UI；检查点持久化待实现 |
| CH-01/03、M03 §2 | 角色移出业务绘制，独立版本化技术占位预设；发呆、玩耍、看窗外、睡眠、醒来、互动及对话动作 | 当前是程序绘制占位，不是正式PNG帧资源包；manifest校验、原子换包和认可原稿待完成 |
| PRD 12 | 雨窗、观察倾向、高温饮品、夜灯与暗色场景 | 全部为模拟天气，无真实来源与新鲜度管理 |
| LF-05、PRD 10–11 | 手动空房间与返程/贴纸画面预览，外出仍能模拟对话 | 未实现旅行调度、预生成、来源归档；演示台词不是生成经历 |
| UI-02/03/04、PRD 15–17 | A短按互动/350ms长按；B返回不清除临近提醒；Start始终打开菜单；上下选择+A进入占位页；Select简况 | 工具页仅入口，实体去抖、方向连发、到期提醒焦点仲裁待实现 |
| PRD硬件约束 | 已改为Gamepad3 A004-V3，按官方三代尺寸图修订A/B位置 | 装配遮挡、触摸和完整尺寸待实机核验 |

验证：`node --test`，并检查浏览器自动睡眠、手动玩耍/雨景、菜单选择和返回。输入测试不能替代产品或硬件验收。

硬件依据：https://docs.m5stack.com/en/faces/Faces_Gamepad3 ，面板标称57.0×54.1×10.7mm。按键中心按官方正视图比例估算，不作加工尺寸。
