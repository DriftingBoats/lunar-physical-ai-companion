# Lunar 开发项目

已确认架构：Core 直连云端语音和对话模型，云端保存/检索完整记忆，Core保留有限缓存，PWA网页用于手机/电脑按需管理。Lunar为默认预设，支持更换角色、形象、人格和声音。

**当前交付仅为需求与开发文档，固件、云服务、PWA和实机测试尚未实现。**
